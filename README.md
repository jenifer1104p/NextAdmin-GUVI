# 🛡️ NexAdmin-GUVI

A modern User Management System built using **PHP, MySQL, MongoDB, Redis, AJAX, jQuery, and Bootstrap 5**.

This project demonstrates user authentication, CRUD operations, profile management, and session handling using multiple databases and modern web development practices.

---

# 📌 Features

- User Registration
- User Login
- Dashboard
- User Management (CRUD)
- Profile Management
- Dashboard Statistics
- AJAX-based operations
- Bootstrap 5 Responsive UI
- Redis Session Storage
- MongoDB Profile Storage
- MySQL User Storage
- Prepared Statements
- jQuery Integration

# ⚙ Installation

1. Clone the repository

```
git clone <your-github-repository-url>
```

2. Open the project in XAMPP

```
htdocs/NexAdmin-GUVI
```

3. Start:

- Apache
- MySQL
- MongoDB
- Memurai (Redis)

4. Install dependencies

```
composer install
```

5. Create the MySQL database

```
nexadmin_guvi
```

6. Run the project

```
http://localhost/NexAdmin-GUVI
```
